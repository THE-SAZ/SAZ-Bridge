## 🌉 SAZ Bridge چیست؟

**SAZ Bridge** یک پنل مدیریت ساب‌لینک فوق‌حرفه‌ای است که بر بستر **Cloudflare Workers** اجرا می‌شود. اگر شما یک ارائه‌دهنده‌ی V2Ray / Xray / Vmess / Vless هستید، این پنل به شما اجازه می‌دهد که:

- 🎯 **کاربران** خود را با یک رابط کاربری زیبا مدیریت کنید
- 🔗 **ساب‌لینک‌های Base64** بسازید که در تمام کلاینت‌های معروف کار می‌کنند
- 📦 **گروه‌بندی** حرفه‌ای کاربران و ساب‌ها
- 🤖 **ربات تلگرام** را بدون یک خط کد اضافه یکپارچه کنید
- 🌍 پنل را به **۴ زبان** نمایش دهید
- 🎨 از **تم واقعی Windows XP** لذت ببرید

> 💡 **چرا Cloudflare Workers؟**
> رایگان، فوق‌سریع، بدون نیاز به VPS، توزیع‌شده در ۳۰۰+ نقطه‌ی جهان، و با SSL رایگان.

## 🚀 نصب سریع

### روش ۱ — Dashboard Cloudflare (ساده‌ترین)

```text
۱. وارد dash.cloudflare.com شوید
۲. Workers & Pages → Create → Worker
۳. نام: saz-bridge
۴. کد _worker.js را Paste کنید
۵. KV Namespace بسازید با نام SUB_KV
۶. در Settings → Variables → KV Bindings اضافه کنید:
      Variable name: SUB_KV
۷. Deploy
```

### روش ۲ — Wrangler CLI (حرفه‌ای)

```bash
# کلون
git clone https://github.com/THE-SAZ/saz-bridge.git
cd saz-bridge
npm install

# ساخت KV
npx wrangler kv:namespace create "SUB_KV"
npx wrangler kv:namespace create "SUB_KV" --preview
# خروجی را در wrangler.toml جای‌گذاری کنید

# Deploy
npx wrangler deploy
```

### 🌟 اولین اجرا (Setup Wizard)

پس از Deploy، آدرس Worker را باز کنید. **Setup Wizard** ظاهر می‌شود:

| مرحله | توضیح |
|--------|--------|
| ۱ | 🔑 رمز عبور مدیر را تعیین کنید |
| ۲ | 🛣️ مسیر ساب‌لینک را وارد کنید (پیش‌فرض: `sub`) |
| ۳ | 🌍 زبان پیش‌فرض را انتخاب کنید |
| ۴ | 🎨 تم را انتخاب کنید |
| ۵ | 🤖 توکن ربات (اختیاری) |

> ✅ **دیگر نیازی به Secrets یا متغیرهای محیطی نیست!** همه چیز در KV ذخیره می‌شود.

## 🚀 Quick Install

### Method 1 — Cloudflare Dashboard (easiest)

```text
1. Go to dash.cloudflare.com
2. Workers & Pages → Create → Worker
3. Name: saz-bridge
4. Paste the _worker.js code
5. Create a KV Namespace named SUB_KV
6. In Settings → Variables → KV Bindings add:
       Variable name: SUB_KV
7. Deploy
```

### Method 2 — Wrangler CLI (pro)

```bash
# Clone
git clone https://github.com/THE-SAZ/saz-bridge.git
cd saz-bridge
npm install

# Create KV
npx wrangler kv:namespace create "SUB_KV"
npx wrangler kv:namespace create "SUB_KV" --preview
# Place the output in wrangler.toml

# Deploy
npx wrangler deploy
```

## 🌉 Что такое SAZ Bridge?

**SAZ Bridge** — это мощный менеджер подписок, работающий на **Cloudflare Workers**. Если вы провайдер V2Ray / Xray / Vmess / Vless, эта панель позволит вам:

- 🎯 Управлять **пользователями** через красивый интерфейс
- 🔗 Генерировать **Base64-подписки**, совместимые со всеми популярными клиентами
- 📦 **Организовать** пользователей и подписки в группы
- 🤖 Интегрировать **Telegram-бота** без единой лишней строки кода
- 🌍 Отображать панель на **4 языках**
- 🎨 Наслаждаться **аутентичной темой Windows XP**

> 💡 **Почему Cloudflare Workers?**
> Бесплатно, молниеносно, без сервера, распределено по 300+ точкам мира, с бесплатным SSL.

```text

4. Вставьте код _worker.js
5. Создайте KV Namespace с именем SUB_KV
```

```bash
# Клонировать
```
